# 🛡️ Система AI-модерации отзывов, комментариев и заявок

Полнофункциональная двухуровневая система автоматической модерации пользовательского контента с защитой от Prompt Injection, спама, скрытых ссылок, токсичности, системой жалоб пользователей и многоязычной административной панелью с мгновенным переводом на русский и узбекский языки.

Проект разработан в точном соответствии со спецификацией **SPEC**.

---

## 🏗️ Архитектура системы

```
[Пользовательский ввод]
      │
      ▼
[Этап 1: Pre-check (RegEx)] ────────(Нарушение)───────> [Мгновенный отказ 422 / Блокировка кнопки]
      │
  (Успешно)
      │
      ▼
[Этап 2: AI-модерация (Gemini)] ────(Нарушение правил)──> [Отклонение 422 / REJECTED_BY_AI]
      │
  (Успешно)
      │
      ▼
[Публикация (PUBLISHED) + Перевод RU/UZ для панели модератора]
      │
      ▼
[Этап 3: Пост-модерация] ───────────(Жалобы пользователей)─> [Карантин при N >= 3 жалоб]
```

## 🌟 Ключевые возможности

### 1. Уровень 1: Предварительная фильтрация (RegEx)
* **На клиенте (Real-time):** При вводе в текстовое поле скрипт в реальном времени анализирует текст. При нахождении ссылок, номеров карт, контактов или мата кнопка «Отправить» блокируется с выводом предупреждения.
* **На бэкенде:** Проверка дублируется перед обращением к Gemini API для строгой экономии токенов и квот. Заблокированные попытки фиксируются в `regex_logs`.
* **Что отсекается:**
  * Ссылки (`http://`, `https://`, `t.me/`, `.ru`, `.uz`, `.com`, `t . m e /`, `точка ком`, IP-адреса).
  * Номера банковских карт (16 цифр: `8600...`, `9860...` и др.).
  * Номера телефонов (`+998...`, `+7...`, локальные).
  * Электронная почта и `@юзернеймы`.
  * Стоп-слова и мат на русском, узбекском (латиница и кириллица) и английском языках.

### 2. Уровень 2: AI-модерация и перевод (Google Gemini API)
* **Модель:** `gemini-2.5-flash` (высокая скорость ~1с и строгий структурированный JSON).
* **Защита от Prompt Injection:** Пользовательский ввод изолируется внутри XML-тегов `<user_message>...</user_message>`. Системный промпт жестко инструктирует модель игнорировать любые внутренние директивы.
* **Анализ нарушений:**
  * `SPAM`: Реклама сторонних услуг, бессмысленный текст.
  * `LINKS_AND_CONTACTS`: Скрытые контакты словами (*«ищите в телеге по нику...»*).
  * `CTA`: Призывы к действию (*«подписывайся»*, *«пиши в лс»*, *«переходи»*).
  * `INSULT`: Пассивная агрессия, завуалированные оскорбления, сарказм, искажения слов (`д*у*р*а*к`).
* **Двуязычный перевод:** Каждое сообщение автоматически переводится на русский (RU) и узбекский (UZ Latin) языки для панели модератора.
* **Отказоустойчивость:** При таймауте (>5 сек) или недоступности API сообщение не теряется, а сохраняется со статусом `PENDING_MODERATION`.

### 3. Уровень 3: Система жалоб (Пост-модерация)
* Кнопка «Пожаловаться» у каждого опубликованного сообщения.
* Модальное окно с выбором категорий: `SPAM`, `INSULT`, `LINKS`, `CTA`, `OTHER` + комментарий.
* **Защита от накрутки:** 1 пользователь (по IP или ID) может пожаловаться на сообщение только один раз.
* **Автоматический карантин (Auto-hide):** При получении 3 жалоб (настраивается в конфиге) статус меняется на `QUARANTINED`, и сообщение скрывается с сайта до решения модератора.

### 4. Уровень 4: Административная панель модератора
* Доступна по адресу: `http://localhost:8000/admin`.
* **Очереди сообщений:**
  1. **⚠️ Требуют внимания:** Жалобы, сообщения в карантине (`QUARANTINED`) и сомнительные (`PENDING_MODERATION`).
  2. **📋 Все сообщения:** Полный поток сообщений с фильтрами по статусам и типам (`REVIEW`, `COMMENT`, `TICKET`).
  3. **🛡️ Лог блокировок RegEx:** Статистика отбитых попыток отправки спама и ссылок.
* **Карточка модератора (3 колонки текста):**
  * **Оригинал** с бейджем определенного языка.
  * **Перевод на Русский (RU)** от Gemini.
  * **Перевод на Узбекский (UZ)** от Gemini.
  * **Вердикт AI:** Уверенность (в процентах), теги нарушений, текстовое пояснение (`reason_ru`).
  * **Блок жалоб:** Количество и список причин, указанных пользователями.
  * **Быстрые действия:**
    * `[✅ Одобрить / Вернуть на сайт]` — статус `PUBLISHED`, сброс жалоб, флаг `verified_by_human = true` (защита от повторного авто-карантина).
    * `[🚫 Отклонить]` — статус `REJECTED_BY_ADMIN`.
    * `[🔨 Забанить автора]` — моментальная блокировка аккаунта/IP.
    * `[🔄 Повторить AI перевод]` — принудительный перевызов Gemini.

## 🚀 Быстрый старт

### 1. Требования
* Python 3.10+ (протестировано на Python 3.13)

### 2. Установка зависимостей
```bash
python -m venv .venv
.\.venv\Scripts\activate
pip install -r requirements.txt
```

### 3. Настройка окружения (`.env`)
Создайте или отредактируйте файл `.env`:
```env
GEMINI_API_KEY=ваш_ключ_от_Google_AI_Studio
GEMINI_MODEL=gemini-2.5-flash
DATABASE_URL=sqlite+aiosqlite:///./moderation.db
QUARANTINE_THRESHOLD=3
AI_TIMEOUT_SECONDS=5.0
CONFIDENCE_APPROVE_THRESHOLD=0.80
CONFIDENCE_REJECT_THRESHOLD=0.85
RATE_LIMIT_PER_MINUTE=20
```

> **Примечание:** Если `GEMINI_API_KEY` не указан, проект всё равно работает! Входящие сообщения автоматически сохраняются со статусом `PENDING_MODERATION` и попадают в админ-панель на ручную проверку.

### 4. Запуск сервера
```bash
.\.venv\Scripts\python run.py
```
Или напрямую через uvicorn:
```bash
.\.venv\Scripts\uvicorn app.main:app --host 0.0.0.0 --port 8000 --reload
```
